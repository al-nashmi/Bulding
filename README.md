# مصاريف البناء

موقع بسيط (بدون سيرفر) لتتبع مصاريف مشروع بناء:

- **الوارد**: الحوالات المستلمة من الوالد (بنك أو كاش).
- **التحويلات**: السحب من البنك إلى الكاش أو العكس، مع رصيد كل حساب.
- **العقود**: مع كل مقاول أو مورد، مع الزيادات والأعمال الإضافية، والمدفوع والمتبقي.
- **جدول دفعات العقد**: دفعة مقدمة، دفعات على مراحل، ودفعة بعد التسليم (بالمبلغ أو النسبة)، مع دفع أي مرحلة على أجزاء، وقائمة بالدفعات المستحقة في الرئيسية.
- **الدفعات والمصاريف**: مربوطة بالعقد أو مصروف مباشر، مع البند والحساب اللي دفعت منه.
- **الفواتير**: إرفاق صور أو PDF لأي دفعة أو عقد أو زيادة.
- **مستندات المبنى**: الصك، رخصة البناء، المخططات، تقرير التربة وغيرها، مع أكثر من ملف لكل مستند وتنبيه بانتهاء الصلاحية.
- **نسخ احتياطي**: تصدير واسترجاع كامل (JSON يشمل الفواتير)، وتصدير الحركات إلى Excel (CSV).

## التشغيل

افتح `index.html` مباشرة، أو فعّل GitHub Pages على هذا الفرع.

> البيانات تُحفظ في متصفح الجهاز (IndexedDB) فقط. خذ نسخة احتياطية بشكل دوري.
